## قواعد الشغل (ثابتة)

1. كل مرحلة بتخلص بتطبيق شغال: `tsc` + `eslint` + unit + e2e (عربي/إنجليزي، فاتح/داكن، ديسكتوب/موبايل) كلهم أخضر.
2. مفيش نص UI في الكود (كله في `messages/`)، ومفيش لون في الكود (كله في `src/lib/brand.ts` / tokens).
3. كل تغيير في الـ schema بـ migration، والـ seed يتحدث معاه.
4. الـ docs بتتكتب مع المرحلة مش بعدها.
5. أي فكرة جديدة برا المخطط تتكتب في `docs/ideas.md` وما تتنفذش.
