# Credits

## Images

- **Product artwork** is generated by the application itself (`src/app/img/[slug]/route.ts`): the Ember Roastery bean mark on a roast-brown ground, one variation per product slug. No photograph and no third-party image host is used, so the demo is self-contained and always on brand. Replace the `images` of a product (dashboard, product form) with real photos when they exist.
- **Logo and brand artwork** (`public/logo-*.svg`, `src/app/icon.svg`) were designed for this project; the colors live in `src/lib/brand.ts`.

## Libraries

Next.js, React, Prisma, Better Auth, Zod, React Hook Form, TanStack Query and Table, Zustand, Recharts, Tailwind CSS, next-intl, React Email, `@react-pdf/renderer`, Papa Parse, pino, Vitest, Playwright, Storybook and the rest of `package.json`, each under its own open-source license.

## Content

The catalog (names, origins, tasting notes, descriptions in both languages) was written by hand for this project. Customer names, addresses and orders are generated with `@faker-js/faker` and are fictional. Reviews on the home page are labelled as demo content.
