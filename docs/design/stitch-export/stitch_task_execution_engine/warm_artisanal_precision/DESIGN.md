## Brand & Style

This design system expresses the craft, warmth, and quiet obsession of specialty coffee roasting, balancing sensory artisanal character with the analytical precision required for roasting profiles, inventory management, and high-volume e-commerce checkout.

### Aesthetic Foundation

The visual language merges **Tactile Minimalist Modernism** with an artisanal editorial layer. Surfaces recall physical elements of the roastery: steamed crema, raw jute bags, cast iron drums, and warm embers. The atmosphere is confident, grounded, and unhurried—rejecting sterile tech minimalism in favor of rich, organic undertones anchored by structured typography and razor-sharp structural framing.

### Emotional Target

- **Consumers:** Sensual, reassuring, tactile, and premium. Conveying single-origin integrity and intentionality.
- **Roastery Admins:** Focused, calm, high-density clarity for green bean batch tracking, cupping notes, order logistics, and roast curve monitoring.

## Colors

The palette is tuned around roasted profiles and ceramic wares, balancing light-mode crema ceramics with dark-mode roaster cast-iron finishes.

### Light Palette (Crema & Roast)

- **Canvas / Background:** `#FAF6F1` (Warm Crema)
- **Surface / Cards:** `#FFFFFF` (Porcelain White)
- **Subtle Surface / Tint:** `#F4EDE3` (Washed Parchment)
- **Border / Structure:** `#E6DCD1` (Natural Linen)
- **Text Primary:** `#1C1612` (Espresso Roast)
- **Text Secondary / Muted:** `#6B5748` (Cocoa Dust)
- **Accent Primary:** `#C2410C` (Ember Orange)
- **Accent Interactive Hover:** `#A8360A` (Deep Ember)
- **Accent Focus / Glow:** `#FFA15C` (Radiant Heat)
- **Destructive / Error:** `#B91C1C` (Crimson Cherry)
- **Text on Accent:** `#FFFFFF`

### Dark Palette (Charred Drum & Glow)

- **Canvas / Background:** `#17110D` (Cast Iron Shadow)
- **Surface / Cards:** `#211914` (Carbon Roast)
- **Subtle Surface / Tint:** `#2B2019` (Smoked Oak)
- **Border / Structure:** `#3A2C23` (Cured Bark)
- **Text Primary:** `#F3ECE4` (Unbleached Silk)
- **Text Secondary / Muted:** `#B8A394` (Toasted Husk)

### Color Rules

- Primary ember colors indicate affirmative primary interactions, progress meters on roast batches, and transactional conversion buttons.
- Secondary tones carry metadata, roast profiles, processing methods (e.g., Anaerobic, Washed, Natural), and cupping metrics.
- Glow colors are reserved for status indicators (e.g., live drum roaster active, freshly dropped lot).

## Typography

The typographic hierarchy distinguishes expressiveness from utility:

1. **Brand & Display Layers:** Set in `Bricolage Grotesque` (weight 800) for packaging headers, heroic marketing moments, cupping lot origins, and key dashboard metric totals.
2. **Interface & Data Layers:** Set in `Geist` (or `Inter` fallback) for high-density administrative views, roast logs, checkout flows, and operational tables.
3. **Bi-Directional Arabic Script:** All Arabic interfaces dynamically map to `IBM Plex Sans Arabic`, ensuring equivalent weights (Bold for Display, Medium/Regular for Body and Meta) with matching line-height adjustments (+2px line-height for Arabic script to prevent diacritic clipping).

### Currency & Metrics

- All pricing defaults to USD with clean mono-spaced numerals (`font-feature-settings: 'tnum' 1;`).
- Cupping score badges and inventory kilograms utilize uppercase bold labels (`label-mono`).

## Layout & Spacing

A strict **4px foundational rhythm** governs all layouts, maintaining tactile alignment across storefront showcases and analytical tools.

### Grid Framework

- **Mobile (< 768px):** 4-column fluid grid, 16px margins, 16px gutters. Bottom sheets and stacked vertical flows.
- **Tablet (768px – 1024px):** 8-column fluid grid, 32px margins, 16px gutters. Split cupping charts and side-by-side ordering panels.
- **Desktop (1025px+):** 12-column layout max-width bounded at 1440px, 48px margins, 24px gutters. Fixed 260px administrative navigation drawer paired with dynamic split-panel roast data tables.

### Bi-Directional Layout Rules (RTL & LTR)

- Layout primitives strictly utilize CSS Logical Properties (`margin-inline-start`, `padding-inline-end`, `inset-inline`).
- When direction is `rtl` (Arabic):
  - Primary navigation shelves anchor on the right.
  - Price tags maintain left alignment in data grids to preserve mathematical scanning.
  - Directional icons (arrows, chevrons, roast workflow steppers) mirror across the vertical axis.

## Elevation & Depth

Visual hierarchy avoids heavy drop shadows, employing **crisp 1px boundary lines combined with subtle tonal layering and ambient warmth**.

### Depth Layers

- **Base Canvas (Level 0):** Unraised background layer (`#FAF6F1` light / `#17110D` dark).
- **Cards & Data Grids (Level 1):** Solid white or charcoal base framed by a 1px border (`#E6DCD1` light / `#3A2C23` dark). No vertical offset shadow; distinction is achieved through pure tonal contrast.
- **Floating Overlays & Menus (Level 2):** Quick cart slides, roast parameter popovers, and cupping score sliders use a warm ambient drop:
  - _Light Mode:_ `0 8px 24px -4px rgba(28, 22, 18, 0.08), 0 2px 6px -1px rgba(28, 22, 18, 0.04)` with a 1px border.
  - _Dark Mode:_ `0 12px 32px -4px rgba(0, 0, 0, 0.5), 0 0 0 1px #3A2C23`.
- **Ember Focus & Active States:** Glowing halos use `#FFA15C` with a soft blur: `0 0 0 3px rgba(255, 161, 92, 0.35)`.

## Shapes

The shape system matches human-scale physical artifacts—crisp packaging edges combined with handheld warmth.

### Geometry Rules

- **Interactive Inputs & Buttons:** 8px (`border-radius: 0.5rem`). Delivers stable form ergonomics across both commerce checkout and fast data entry.
- **Cards, Panels & Data Tables:** 12px (`border-radius: 0.75rem`). Ensures nested tables and image headers sit flush within outer envelopes.
- **Hero Panels & Brand Featurettes:** 16px (`border-radius: 1rem`). Softened large surfaces highlighting origin stories and seasonal harvests.
- **Pills, Badges & Cupping Tags:** Fully rounded (`border-radius: 9999px`). High-contrast capsule shape for quick visual filtering (e.g., `Score: 89.5`, `Washed`, `Ethiopia`).

## Components

### Buttons

- **Primary:** Ember Orange fill (`#C2410C` light / `#E4572E` dark), text `#FFFFFF` (light) or `#1C1612` (dark). 8px radius, height 40px (admin) / 48px (consumer checkout). Hover triggers `#A8360A` / `#F0693F`.
- **Secondary / Ghost:** Transparent background with 1px border (`#E6DCD1` / `#3A2C23`), primary text color. Hover shifts surface to `#F4EDE3` / `#2B2019`.
- **Destructive:** Crimson cherry line or fill (`#B91C1C` / `#F87171`) for batch cancellation or raw stock disposal.

### Input Fields

- 8px radius, height 42px, padding `0.75rem 1rem`. 1px border in Linen / Cured Bark.
- Active focus state: 1px Ember Orange border flanked by a 3px radiant glow (`#FFA15C` at 35% opacity).
- Support for inline prefix/suffix currency flags (`$ USD`) and roast metric units (`kg`, `°C`, `ROR`).

### Chips & Badges

- Pill-shaped (`rounded-full`), height 24px, padding `0.25rem 0.75rem`, label-md font.
- Taste Note Tags (e.g., _Bergamot_, _Dried Fig_, _Jasmine_): Subtle warm background `#F4EDE3` with secondary text `#6B5748`.
- Availability/Roast Stage: Small 6px dot inside the chip pulsing active ember for _Currently Roasting_.

### Cards

- 12px radius, 1px perimeter border.
- **Coffee Lot Card:** 4:3 product image container flush to top, followed by 16px interior padding containing Country, Washing Station, Roast Level bar, Cupping Note pills, and clear price/weight toggle.
- **Admin Metric Card:** Minimal padding (16px), large headline-sm metric, label-mono descriptor, and micro-sparkline of roasting batch temperatures.

### Tables & Admin Lists

- Alternating subtle rows (`#FAF6F1` vs `#FFFFFF` in light mode; `#17110D` vs `#211914` in dark mode).
- 1px continuous dividers.
- Dense vertical padding (10px) with numeric values monospaced and aligned to trailing edges (`text-align: end`).

### Bi-Directional Adaptations

- Checkbox and radio indicators anchor cleanly to the logical start edge (`margin-inline-end: 0.75rem`).
- Dismiss and trailing action buttons map seamlessly to the opposite inline corner.
